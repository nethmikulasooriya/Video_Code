

\# VideoCode



VideoCode is a Python-based desktop tool that extracts and reconstructs source code from programming tutorial videos using OCR and screen capture.



\## Features



\- Select a specific screen area to capture.

\- Automatically capture screen frames.

\- Detect stable code states.

\- Extract code using OCR.

\- Reconstruct code from captured frames.

\- Copy or save the extracted code.



\## Technologies Used



\- Python

\- OpenCV

\- Tesseract OCR

\- MSS

\- Tkinter



\## Project Status



Currently under development.
